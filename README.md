# 🎛️ PA — Switch Case

Repositório de exercícios de Programação e Algoritmos para praticar estruturas de seleção `switch/case` e organizar decisões com múltiplas alternativas.

## 📖 Sobre o projeto

O **PA — Switch Case** reúne atividades e pequenos projetos que ajudam a compreender como selecionar diferentes caminhos de execução conforme o valor de uma expressão.

## ✨ Conteúdo

- 🔀 Exercícios com `switch/case`.
- 🧠 Prática de lógica de programação.
- 📚 Atividades separadas em listas e projetos.

## 🛠️ Tecnologias utilizadas

- **Programação:** consulte os arquivos-fonte para identificar a linguagem e o ambiente necessários.

## 🚀 Como executar os exercícios

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/PA-SwitchCase.git
   ```
2. Entre na pasta:
   ```bash
   cd PA-SwitchCase
   ```
3. Abra os arquivos em uma IDE compatível com a linguagem usada nos exercícios.

## 🎯 Objetivo de aprendizagem

Compreender e aplicar a estrutura `switch/case` para resolver problemas com várias opções possíveis.
